Saffron & Ember is a 3D WebGL Mediterranean open-flame bistro cooking game built with Three.js (vendored offline) and procedural Web Audio. Switch between Head Chef Marco and Sous Chef Sofia, toss ingredients across the marble island, sear steaks on live burner flames, wash dirty plates in the running sink, douse grease fires with the extinguisher, and serve VIP orders through escalating dinner rushes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in Chrome. To generate the submission dossier locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
