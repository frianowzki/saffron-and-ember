Saffron & Ember is an original Mediterranean open-flame bistro cooking game for desktop browsers, played with keyboard and mouse with zero external assets or build steps. Chop heirloom produce, time Golden Perfect Sears on the charcoal hearth, assemble combinatorial dishes across a central marble island, and serve VIP orders through escalating dinner rushes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in Chrome. To generate the submission dossier locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
